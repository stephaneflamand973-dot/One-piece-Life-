# ONE PIECE LIFE — QA V9.2

V9.2.0 — NPC Living Lives 5.2

## Objectif

La V9.2 transforme l'autonomie mondiale existante en trajectoires individuelles persistantes. Les PNJ importants continuent de vivre hors écran sans remplacer les moteurs qui gèrent déjà le canon, les némésis, les relations ou les conflits.

## Trajectoires persistantes

Chaque vie suivie peut désormais conserver :

- phase actuelle ;
- objectif personnel ;
- progression d'objectif ;
- palier de carrière générique ;
- progression professionnelle ;
- renommée ;
- influence ;
- aisance matérielle abstraite ;
- énergie ;
- stress ;
- victoires, défaites et revers ;
- déplacements ;
- alliances ;
- jalons connus ;
- historique court borné.

Les paliers de carrière sont descriptifs. Ils ne remplacent jamais les grades ou fonctions canoniques.

## Sources suivies

- personnages mondiaux importants ;
- relations personnelles importantes ;
- équipiers via leur relation ;
- némésis persistantes.

Un personnage canonique déjà présent dans le monde n'est pas dupliqué lorsqu'il existe aussi dans les relations du joueur.

## Monde autonome

La boucle V5.8 reste responsable de la progression de puissance, des conflits, des factions et des pressions régionales.

V9.2 observe et enrichit ces événements :

- déplacement ;
- victoire ou défaite ;
- coopération ;
- influence ;
- obtention d'un Fruit ;
- récupération ;
- changement de phase ;
- progression professionnelle ;
- objectif accompli.

## Relations

Les relations non canoniques peuvent changer de région hors écran.

Ne déménagent pas automatiquement :

- les équipiers actifs ;
- le partenaire actuel ;
- le mentor actif ;
- les personnages canoniques dont le déplacement est déjà contrôlé par le World Director.

Une relation influente peut apporter un petit supplément au soutien de mission V6.7/V7.4.

## Information

La simulation interne est volontairement plus riche que ce que le joueur voit.

- les relations proches rendent leurs grands jalons visibles ;
- les némésis importantes apparaissent dans l'historique ;
- seuls les jalons mondiaux suffisamment importants sont publiés dans le journal.

Cela évite de transformer le monde vivant en flux d'actualités permanent.

## Sauvegarde

- maximum 90 trajectoires persistantes ;
- historique global V9.2 limité à 50 entrées ;
- historique individuel limité à 8 entrées ;
- jalons individuels limités à 10 entrées.
