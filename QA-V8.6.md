# ONE PIECE LIFE — QA V8.6

V8.6.0 — Daily Life & Opportunities 4.0

## Objectif

La V8.6 enrichit le temps entre les grands événements. L'activité principale devient une trajectoire persistante et le monde produit de petites occasions cohérentes sans interrompre constamment la simulation.

## Maîtrise d'activité

Le moteur suit pour chaque type :
- mois pratiqués ;
- maîtrise 0–100 ;
- meilleure série ;
- succès liés ;
- événements produits.

La maîtrise n'efface aucun ancien système de progression. Elle applique seulement un modificateur limité aux gains déjà calculés par les moteurs précédents.

## Séries et habitudes

Rester sur la même activité :
- augmente la série mensuelle ;
- améliore légèrement l'efficacité ;
- fait monter la maîtrise.

Changer d'activité :
- remet la série actuelle à 1 ;
- conserve toutes les maîtrises ;
- réduit la fatigue de routine.

## Fatigue de routine

Après une longue répétition, la routine devient moins productive.

Le système empêche donc une stratégie optimale consistant à conserver la même activité pendant quarante ans parce qu'un humain a découvert qu'un chiffre vert pouvait monter.

## Micro-événements

Le quotidien peut produire sans interruption :
- petit déclic ;
- travail remarqué ;
- bonne surprise financière ;
- fatigue ;
- moment partagé ;
- observation utile.

Ils restent rares et espacés pour ne pas noyer la chronologie.

## Opportunités facultatives

Jusqu'à trois opportunités peuvent rester ouvertes en parallèle.

Elles n'interrompent jamais l'avance annuelle et restent visibles pendant 18 mois.

Types :
- défi local ;
- partenaire d'entraînement ;
- petite cible ;
- secours ;
- piste locale ;
- rumeur de butin ;
- information sensible ;
- recherche ;
- contact ;
- affaire marchande ;
- contrat ;
- invitation ;
- anomalie ;
- coup opportuniste.

## Résolution dynamique

La chance dépend de :
- compétence associée ;
- puissance ;
- maîtrise de l'activité ;
- énergie ;
- réputation mondiale ;
- difficulté de l'occasion.

Une résolution peut être :
- succès ;
- résultat partiel ;
- échec.

## Conséquences

Les opportunités peuvent modifier :
- argent ;
- réputation ;
- énergie ;
- santé ;
- compétence ;
- relation ;
- piste rare ;
- exploration de l'île.
