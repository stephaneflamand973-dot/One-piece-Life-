# ONE PIECE LIFE — QA V8.4

V8.4.0 — Crew & Organization 4.0

## Objectif

La V8.4 transforme l'équipage du joueur en système stratégique complet. Les membres ne sont plus seulement des bonus de moral : leurs rôles, leur maîtrise, leur loyauté, leurs blessures et leur complémentarité déterminent ce que l'organisation est réellement capable d'accomplir.

## 11 rôles

- Combattant
- Sabreur
- Tireur
- Navigateur
- Médecin
- Charpentier
- Cuisinier
- Éclaireur
- Musicien
- Savant
- Officier

Chaque rôle possède des affinités distinctes pour le combat, la navigation, le soutien, le commandement et les différents types de mission.

## 6 doctrines d'équipage

- Équilibré
- Offensive
- Exploration
- Survie
- Discipline
- Liberté

La doctrine modifie réellement les performances collectives. Elle ne constitue pas un simple libellé cosmétique.

## Membres persistants

Chaque équipier V8.4 possède :
- un rôle ;
- un trait personnel ;
- une puissance et un potentiel ;
- une croissance ;
- une maîtrise de poste ;
- loyauté et confiance ;
- expérience ;
- historique de missions ;
- blessures et durée de récupération ;
- statut hiérarchique.

## Second officiel

Un capitaine peut nommer un membre comme second. La promotion :
- est persistante ;
- renforce son poids dans le commandement ;
- augmente loyauté et confiance ;
- apparaît dans l'interface d'équipage.

## Couverture des rôles et synergie

Le moteur suit notamment quatre fonctions essentielles :
- combattant ;
- navigateur ;
- médecin ;
- charpentier.

La synergie combine moral, cohésion V6.7, tension, préparation, réserves et couverture des rôles.

Un grand équipage mal construit n'est donc plus automatiquement meilleur qu'une petite équipe cohérente.

## Équipes de mission

Pour chaque mission, le moteur sélectionne automatiquement jusqu'à trois membres les mieux adaptés au type de tâche.

Les équipiers choisis apportent un bonus réel à la préparation de mission selon :
- puissance ;
- rôle ;
- maîtrise ;
- loyauté ;
- expérience ;
- doctrine ;
- synergie ;
- état physique.

Les résultats sont ensuite mémorisés par les membres ayant réellement participé.

## Blessures

Les membres peuvent être blessés :
- pendant l'activité normale à haut risque ;
- lors d'une mission difficile ou ratée.

Un équipier blessé reste dans l'équipage mais contribue beaucoup moins jusqu'à sa récupération.

## Recrutement ciblé

L'action Recruter analyse les rôles manquants avant de générer un candidat.

La probabilité qu'il accepte dépend de :
- la renommée de l'équipage ;
- la réputation mondiale ;
- le commandement du joueur ;
- la taille du groupe ;
- le fait que son rôle soit réellement nécessaire.

## Gestion annuelle

Une action majeure d'équipage peut être menée par an :
- entraînement collectif ;
- cohésion ;
- logistique et navire ;
- recrutement.

Ces actions consomment d'abord la caisse de bord, puis les fonds personnels si nécessaire.

## Priority Director

Les crises internes V6.7 sont désormais transmises au Priority Director V8.0.

Un conflit d'équipage entre donc en concurrence avec :
- vie personnelle ;
- conséquences ;
- faction ;
- campagne ;
- némésis ;
- autres décisions majeures.

On évite ainsi les interruptions empilées uniquement parce que plusieurs systèmes ont décidé d'être dramatiques le même mois.

## Campagnes V8.2

L'équipage contribue désormais au score d'organisation utilisé dans les campagnes régionales.

Une équipe forte en commandement, coordination et rôles complémentaires rend donc le joueur plus efficace dans les décisions de saga.

## Délégation

La qualité de l'équipage intervient aussi dans les missions déléguées V6.9. Les missions déléguées sont enregistrées dans l'historique du roster et peuvent produire des blessures.

## Interface

Le panneau Équipage affiche désormais :
- nombre de membres ;
- couverture des rôles clés ;
- préparation ;
- réserves ;
- renommée ;
- état du navire ;
- bilan des missions ;
- puissance collective ;
- Combat / Navigation / Soutien / Commandement ;
- doctrine ;
- roster détaillé ;
- second ;
- blessures ;
- actions de gestion ;
- candidats au recrutement.
